# Where Stretch is going

Stretch is an early prototype. This is a direction for discussion, not a release schedule.

## Working today

- Native Mac menu-bar app and a transparent companion panel.
- Optional timed nudges, daily working hours and snooze.
- A skippable first-run introduction with real movement trials and menu-bar guidance.
- Pip’s standing, seated and breathing movements.
- Editable character sources and a browser interaction demo.

## Next improvements

- A signed, notarised download.
- Launch at login and custom working days/hours.
- More complete keyboard, accessibility and reduced-motion support.
- Better transitions between seated and standing states.
- A smaller animation package while preserving transparent edges and movement quality.

## Explore together

- A shared asset format, character picker and more companions.
- Context-aware pauses around idle time, Focus, calls and presentations.
- Ports beyond Apple Silicon macOS.

Suggestions and contributions are welcome through [issues](https://github.com/jack-robinson-software/stretch/issues). Keep Stretch quiet, optional and easy to dismiss as it grows.
