# Pip — native Mac prototype

Run `./build.sh`, then open `Pip.app`. Pip lives in the menu bar and appears in a small transparent panel at the top right of the screen. The welcome window contains the reminder settings and a way to try him immediately.

## Try it

- **Say hello:** a wave, then an invitation. Choose **Stay seated**, **Get moving**, or **Not now**.
- **Stay seated:** side reaches, gentle turns, shoulder rolls and breathing. **Another** cycles through these movements. Pip stays in his chair when you finish, then quietly fades away.
- **Get moving:** standing stretches and breathing. Pip celebrates, then walks off when you finish.
- **All done:** finish early. **Back to it:** dismiss the completion message.
- **Menu bar:** bring Pip back, try either type of pause, snooze for 15 minutes, open settings or quit.
- **Settings:** choose 15, 30, 45 or 60 minutes and either any time, 9–5 or 9–6. Enable gentle nudges when ready. Reminders start **off**. Working hours apply every day.

Nudges are silent. Showing the companion does not activate the app or take keyboard focus. The character and empty transparent space let mouse clicks pass through; the speech bubble accepts clicks. The settings window activates only when explicitly opened, including first launch.

## Build and verify

Requires an Apple Silicon Mac, macOS 13+, and Apple Command Line Tools. No package downloads or Xcode project are required.

```sh
./build.sh
./Pip.app/Contents/MacOS/Pip --self-test
open Pip.app
```

`--self-test` checks state transitions, reminder defaults and working-hour boundaries, the seated completion state, and all ten packaged animation sequences. `--capture /absolute/output/path` renders the invitation, seated, standing, completion and settings views for inspection, then exits. The view cache capture does not include the settings window's background or some layer-backed native controls; it is not a full window screenshot.

`package_assets.py` repackages the approved animation renders as 300×360 transparent PNG frames, retaining 30 fps. The player uses elapsed time and a limited image cache, and stops rendering when hidden. The approved Blender model and movements are not modified by the app.

## Files

- `Sources/`: AppKit application, state, scheduling, native controls and animation player.
- `Pip.app/`: bundle template and all transparent animation resources (about 100 MB). The executable and local signature are generated by `build.sh`.
- `preview.html`: portable interactive visual demo with relative asset paths. Open it directly in a browser, or serve the repository root and visit `/mac-app/preview.html`.
- `qa/`: rendered native views.

## Prototype scope

This is a working local desktop prototype. Reminders use a timer and the chosen work hours; they do not yet detect idle time, calls, Focus modes or fullscreen presentations. Settings persist locally in UserDefaults. There are no accounts, network requests, AI calls, telemetry, or camera/microphone/screen permissions in Pip. The app samples the pointer location while visible to make its transparent area click-through; it does not record input.

Distribution signing/notarization, launch at login, a polished application icon, a compact production animation format, custom working days and a rendered sit/stand transition are future product work. The inline preview demonstrates the controls but does not schedule OS reminders.
